# Provenance

The project began as an attempt to verify a conversation. Owner:
[`docs/origin/`](../../../../docs/origin/) - append-only, sixteen source artifacts,
plus a transcript and its audit.

## What is established

- **The headline claim was wrong by 6.84x.** The source asserted **531,441**
  distinct reachable behaviours where the measured truth is **77,687** (`P5`). That
  single discrepancy is why every claim in this repository is now registered before
  it is measured.
- **The source's code was recovered and preserved**, including three code blocks
  that had been collapsed in the original view and would otherwise have been lost.
- **Provenance is append-only.** `docs/origin/` is never edited, only added to, so
  the thing being checked cannot drift toward the checker.

## Sub-topics (the rabbit hole)

- Which of the source's other claims survived, and which were never testable
- The 531,441 coincidence: the wrong number is also a real ceiling elsewhere
- What an audit of a conversation should preserve, and in what form

## Open questions

- Several source claims have never been separately checked because no tool existed
  for them. Which are still open?
- Is 531,441 appearing both as the wrong claim and as a genuine monoid ceiling
  meaningful, or is it the same exponent arithmetic twice?

## A neighbour outside this repository

`C:/Users/Owen/WaveSeeds` — a feasibility study for a cryptocurrency wallet seed
entered by tapping a **3×3 grid of pitched pads**, where the tap sequence *is* the
secret and audio is only a mnemonic layer. Not a git repository. Vanilla WebAudio
trainers plus offline Python analysis; two finished self-critical reports
(`lab/DISTINCTNESS.md`, `lab2/MUSICALITY.md`), no test suite, and — by its own
admission — **zero human listeners so far**.

It uses none of this project's vocabulary. The words *ternary* and *base-3* never
appear in it. It nonetheless works in the same space and reached several of the same
conclusions independently, which is why it is recorded here rather than left to be
rediscovered.

| there | here |
|---|---|
| the pad grid is ℤ3 × ℤ3 — **two trits** | the arena of `P`–`V` at width 2 |
| log₂9 = 3.17 bits per tap, and log₂3 = 1.585 recurs throughout | `AB3`: a one-trit shift erases exactly log₂3 |
| `split_stream.py` decomposes one 9-symbol stream into two 3-symbol streams: *"nothing is created and nothing is destroyed — the entropy is redistributed, not reduced"* | `AB`'s conservation framing, reached from the other end |
| `subsets.py`: *"three defensible cost units that rank the schemes differently"* | `AC4`: steps and bits rank the same programs differently |
| diatonic fit scored as a maximum over the **twelve transpositions** — a ℤ/12 action | `AE1`: that is the T/I group, which is `AB5`'s group at n = 12 |

**The sharpest agreement is with `AE4`.** WaveSeeds measures repeated 3-grams at
0.31 for random sequences against 6.40 for real tunes and calls it *"a 20× gap that
no choice of pitches can close"*, because a maximum-entropy secret cannot carry the
redundancy music has. `AE4` measured the structural half of the same statement:
1.81% of twelve-tone subsets have transpositional symmetry against 0.00038% in
ℤ/27. One approaches the entropy-versus-structure tension from the sequence side and
one from the space side, and they agree.

It also carries a hard rule worth knowing before anyone reads it as a source of
technique: *"The sequence is generated by `crypto.getRandomValues` and never
composed, edited, or reshuffled by the human… If the trainer ever grows a 'compose
your own' button, the project is dead."*

**Nothing here depends on it and no code has been taken from it.** This is a
pointer, and the tree was read-only.
